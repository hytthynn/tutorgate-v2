# TutorGate — доработки расписания

Полный проект с изменениями по приложенному ТЗ.

1. Начните с **docs/verification.md**: 18 unit/static tests прошли, UI smoke выполнен; полный CI и DB/Cron не подтверждены из-за недоступных npm-зависимостей.
2. Инструкция обновления: **docs/upgrade-006.md**.
3. Примените **supabase/migrations/202609050006_schedule_upgrade.sql** после 001–005. Старые миграции не изменены.
4. Включите и проверьте **Supabase Cron** скриптами **supabase/ops/**. Без фонового job weekly rollover не обеспечивает SLA 5 минут.
5. Установите зависимости из оригинального lockfile и выполните полный набор проверок перед production.

## Основные изменения
- Custom Select/Combobox, поиск и клавиатура; общий Toast; иконки toolbar и completed.
- Числовые поля без спиннеров, день из семи дней недели, auto-grow заметки.
- Полная история, локальная навигация и обновление карточек без router.refresh.
- Атомарный SQL magnet для tutor/student, создание и перенос на ближайшее свободное время.
- Hard delete предметов с lesson snapshots и сохранением истории/статистики.
- Защита будущих недель и идемпотентное автоматическое копирование прошлой недели.

Undo/Redo намеренно disabled. Реальная БД и внешние сервисы пользователя не изменялись.
