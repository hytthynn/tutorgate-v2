5. Magnet для общего student у разных tutor, отсутствие утечки чужих заметок/имён, конкурентные запросы.
6. Rollover по нескольким offset, сброс completion, копирование note, идемпотентность, skip невалидных назначений. Наблюдать реальный запуск Cron не позднее 5 минут после локальной границы недели.
7. Network-проверка отсутствия RSC GET при навигации и CRUD на настоящем Next. Отдельный минутный инкрементальный polling для Cron не является навигационным refetch.

## Границы релиза

- Undo/Redo намеренно только disabled icons/tooltips, как требует ТЗ.
- Cron необходимо включить в Supabase: fallback при открытии/мутации не обеспечивает фоновый SLA сам по себе.
- При длительном простое Cron цепочка нескольких пропущенных недель автоматически не восстанавливается; функция копирует непосредственно предыдущую неделю.
- Полная синхронизация удалений между несколькими одновременно открытыми вкладками не добавлялась; собственные удаления текущей вкладки обновляются локально.
- PostgreSQL использует общий advisory lock для schedule writers: при росте нагрузки необходимы latency/cron-duration измерения.
