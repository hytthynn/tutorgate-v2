# Уточнения пакета 018 — 09.09.2026

Этот документ фиксирует последующий прямой запрос заказчика и заменяет противоречащие ему пункты исходного [ТЗ 018](TZ_TutorGate_018_chat_schedule_rates_background.md).

1. Формулы должны отображаться в Telegram как формулы. Сообщения с формулами отправляются через `sendRichMessage`, с нативными `mathematical_expression` и исходной LaTeX-записью в поле `expression`. Код исключён из поиска формул, некорректная формула остаётся текстом.
2. Выравнивание center/right сохраняется при отправке: в Telegram используется блок таблицы без границ с одной ячейкой и соответствующим `align`; обычные абзацы остаются paragraph. Произвольный CSS в Telegram не передаётся.
3. Блоки кода подсвечиваются также без явного языка, с автоопределением среди ограниченного набора grammar. Копирование и преобразование блока сохраняют переводы строк.
4. Ставка в справочнике репетиторов открывается шестерёнкой справа от имени. Кнопка имеет доступное имя и tooltip.
5. Модальные окна ставок показывают участника/пару, область действия, ставку по умолчанию, подписанное поле с валютой и отдельный ряд действий; адаптированы к мобильным экранам.
6. У стикеров нет строки файла с именем, размером и кнопкой скачивания. Высота контейнера не обрезает стикер и не накладывает его на footer сообщения.
7. Поле МСК не принимает числа вне −12…+12, дроби и посторонние символы во время ввода/вставки. Знаки и пустое значение разрешены как промежуточный draft; Enter/blur сохраняют только целое число.
8. Фон расположен позади всего раздела расписания, включая заголовок и toolbar, с затемнением. Модальное окно фона содержит preview, понятную область загрузки, ограничения форматов/размера, удаление и кнопку завершения.

Нативный Telegram contract проверен по [Bot API — Rich messages](https://core.telegram.org/bots/api#rich-messages). Отправляемые blocks являются структурированными данными, а не пользовательским HTML. Доставка простых сообщений и файлов сохраняет прежний путь; reply mapping использует ID отправленного rich-сообщения. Реальное отображение зависит от поддержки rich messages установленной версией Telegram.

Дополнительной миграции для этих уточнений нет. Права ставок, private Storage, delegated ограничения и snapshot заработка из 018 сохраняются.
