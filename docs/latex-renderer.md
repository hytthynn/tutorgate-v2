# Расширенный LaTeX

Пакет 020 добавляет настройки администратора: имена пакетов, общую преамбулу для `\newcommand`/`\DeclareDocumentCommand`, библиотеки `.sty`/`.asy`. Файл конфигурации Asymptote не требуется. Применить [миграцию 020](../supabase/migrations/202609090020_latex_settings.sql) после 019.

Обычные формулы по-прежнему отображает KaTeX. Для неизвестных ему команд, блоков кода `latex`, `tex`, `tikz`, `asy`, `asymptote` и отдельных окружений `asy`, `tikzpicture`, `tabular`, `tabularx`, `longtable`, `align`, `gather`, `equation` доступна кнопка «Отобразить LaTeX». Она запускает полноценную компиляцию с общими настройками. Результат — PNG в чате или предпросмотре; исходный текст остаётся в сообщении. Настройки проверяются заново при каждом запросе, результат можно обновить. Расширенные рисунки предназначены для веб-чата; этот пакет не меняет Telegram-доставку и не обещает поддержку произвольных пакетов Telegram-клиентом.

Английский/русский включены через UTF-8, T2A/T1 и Babel. В образ входят стандартные коллекции TeX Live: LaTeX base/recommended/extra, pictures, science, Cyrillic, fonts и Asymptote. По умолчанию подключены AMS/Mathtools, TikZ/PGFPlots, Array/Booktabs/Tabularx/Longtable/Multirow/Makecell, Xparse/Etoolbox и Asymptote. Библиотеки TikZ выбираются в преамбуле через `\usetikzlibrary`; модули Asymptote — через `import` в коде. «Добавить пакет» подключает установленный пакет по имени; собственные `.sty` загружаются через форму. Это не установка произвольного CTAN-пакета с зависимостями: отсутствующие системные пакеты добавляются в образ компилятора и требуют его пересборки.

## Запуск сервиса

Нужен отдельный Linux-хост с Node 24 и Docker. Next.js не запускает TeX на своём хосте. HTTP-брокер запускает отдельный одноразовый контейнер на каждый запрос: без сети, application credentials и host mounts, read-only root, непривилегированный UID, ограниченные tmpfs/RAM/CPU/PIDs и время. TeX shell escape отключён, Asymptote запускается в safe mode. Не устанавливать рендерер на хост с рабочими секретами приложения; доступ к Docker даёт брокеру административные права на его выделенном хосте.

Из корня репозитория на хосте компиляции:

```sh
docker build -t tutorgate-latex:local services/latex
export LATEX_RENDER_TOKEN='ЗАМЕНИТЬ_НА_СЛУЧАЙНЫЙ_СЕКРЕТ_МИНИМУМ_32_СИМВОЛА'
node services/latex/server.mjs
```

По умолчанию сервер слушает только `127.0.0.1:3201`. Для подключения отдельного Next.js-хоста используйте закрытую сеть и HTTPS reverse proxy; не открывайте Docker API в сеть. На сервере Next.js задать `LATEX_RENDER_URL=https://PRIVATE-HOST/render` и тот же `LATEX_RENDER_TOKEN`, затем перезапустить приложение. Токен доступен только серверным действиям и не попадает в контейнер компиляции. Признак «настроен» в UI означает наличие переменных, не результат проверки доступности; реальную проверку выполняет кнопка «Сохранить и проверить».

Проверка настоящего движка:

```sh
export LATEX_RENDER_URL=http://127.0.0.1:3201/render
node services/latex/smoke.mjs
```

Smoke требует PNG для русского/английского текста, собственной команды, TikZ, таблицы и Asymptote. На рабочем Windows-компьютере агента Docker/TeX отсутствуют: сборка образа и этот smoke не выполнялись. Браузерный тест использует только локальный fixture-ответ и подтверждает интерфейс, права Server Action и отображение ответа, а не качество TeX-компиляции.

## Примеры

В сообщении, отдельным блоком:

```latex
\begin{asy}
size(150);
draw(unitsquare);
\end{asy}
```

```latex
\begin{tikzpicture}
\draw[->] (0,0) -- (3,0) node[right] {$x$};
\draw (0,0) parabola (2,1);
\end{tikzpicture}
```

Исходный код рисунка ограничен 16 000 символами, при отправке чата сохраняется общий лимит сообщения 4000 символов. Максимум 60 пакетов, 8 библиотек по 16 000 символов, преамбула до 16 000 символов. Рендерер принимает до 200 КБ UTF-8 JSON, выполняет максимум два задания одновременно, завершает контейнер через 45 секунд и возвращает одну страницу PNG до 5 МБ. Многостраничные документы следует разбивать; ошибка не заменяется изображением только первой страницы.
