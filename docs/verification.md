## Актуальный результат

После исправления шести падений из пользовательского E2E-отчёта выполнены проверки на Windows, Node 24.19.0, с установленными проектными зависимостями и Next.js 16.3.4.

| Команда | Фактический результат |
|---|---|
| `npm run lint` | Пройдена, без ошибок и предупреждений |
| `npm run typecheck` | Пройдена |
| `npm test` | 50/50, без пропусков; unit и DB-наборы с миграциями в PGlite |
| `npm run test:docs` | Пройдена |
| `npm run test:e2e` | 34/34, один worker, Chromium; полный прогон 3,5 минуты |

E2E запускает настоящее Next-приложение и локальные Supabase fixtures через `tests/e2e/server.mjs`. Реальные Supabase/Auth, Telegram и staging в этой проверке не использовались. `npm ci` повторно не запускалась; версии зависимостей и lockfile при исправлении тестов не менялись.

## Исправленные причины

- Radix обрабатывал Escape в capture-фазе раньше Select и закрывал весь диалог. Теперь первое нажатие закрывает открытый список и возвращает фокус, второе — диалог. Регрессии покрывают списки с поиском и без него.
- Перенос на пять минут в тесте не пересекал порог начала drag в 7 px. Жест теперь сначала пересекает порог; проверяются preview и сохранение позиции после reload.
- Созданное занятие уже выделено: для открытия редактора нужен один повторный клик. Лишний клик попадал в overlay открытого диалога.
- Смена роли в одном браузерном контексте теперь выполняется после выхода из аккаунта.
- Уведомление ищется внутри области «Уведомления», отдельно от Next route announcer с тем же `role=alert`.
- Проверка удаления больше не принимает скрытую модальным окном кнопку за удалённую: сначала ожидается закрытие диалога. Завершение отложенных мутаций ожидается до конца сценария, чтобы они не меняли fixtures следующего теста.
- Обход административных страниц при четырёх ширинах разделён на независимые тесты; диалоги и навигация проверяются отдельно. Общий таймаут не увеличен.
- Удалена неиспользуемая директива подавления ESLint.

Правила расписания, SQL/RLS, owner-checks, серверный magnet и rollover этим исправлением не менялись. Требования — [текущее ТЗ](TZ_TutorGate_bugfixes_007.md).
